# Security Policy

## Supported Versions

This is an active recompilation project. Security fixes are applied to the current `main` branch.

## Reporting a Vulnerability

If you discover a security issue in the recompilation harness or runtime (not in the original game), please open a private security advisory or contact the maintainer directly rather than filing a public issue.

Do **not** report issues that require game assets or dumps to reproduce if the vulnerability exists only in the original title. This repository contains only the harness.

We will acknowledge reports and work to address confirmed issues in the harness as soon as practical.
