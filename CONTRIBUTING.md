# Contributing

Contributions are welcome.

## Scope

- Runtime fixes, kernel API improvements, and graphics/emulation work are in scope.
- Do not commit game code, assets, or the translated C++ output. Those stay out of the repository.
- Keep changes focused.

## Building

See the README and [docs/SETUP.md](docs/SETUP.md).

## Reporting issues

Include what you expected versus what happened, and any relevant logs.

## Code of Conduct

This project follows a [Code of Conduct](CODE_OF_CONDUCT.md). By participating, you agree to uphold it.
